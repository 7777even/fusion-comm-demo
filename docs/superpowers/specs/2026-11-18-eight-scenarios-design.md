# 化工园区融合通信八大业务场景 — 设计

- 日期：2026-11-18
- 状态：Approved（用户已确认方案）
- 需求源：`化工园区融合通信八大业务场景_建设方案.docx`（V1.0 2026-11-18）
- 接口源：`(openapi)新融合通信系统开放接口文档(1).docx`（V1.3 2026-09-12，申讯）

## 背景与目标

建设方案定义 8 个固定业务场景（平时 2 / 战时 4 / 事后 2），要求 Demo 最终实现这 8 个场景；接口文档定义申讯 OpenAPI V1.3 的可用接口。当前 Demo 已有 5 个基础能力页（态势/电话/广播/信息发布/应急）与 `fcPost` + mock 分层。本次新增 8 个场景页，完整呈现建设方案每场景的七块内容并提供可交互流程。

## 已确认决策

1. **缺口处理**：8/8 场景全做。有接口的能力走 `fcPost`（MOCK 模式由 handler 模拟），无接口的能力（短信收发、GIS 地图、PDT 集群、视频会议 MCU、三维演练等）用拟真数据 + 本地状态机模拟，页面标注「模拟/需对接」。
2. **导航结构**：侧边栏 4 组共 13 项——基础能力（现有 5 页）+ 平时·日常管理（01-02）+ 战时·应急指挥（03-06）+ 事后·总结提升（07-08）。hash 路由新增 `/scene/01-meeting` ~ `/scene/08-drill`。
3. **页面深度**：完整七块内容都呈现（故事/卡片/流程/角色动作/依赖功能/合同边界/验收建议），交互操作嵌入其中。
4. **架构方案**：元数据抽离 + 通用壳（`ScenarioShell.vue` 渲染七块，「流程」页签留 slot 放各场景交互区），8 个 View 只写交互逻辑。

## 接口能力盘点（来自 OpenAPI V1.3）

真实可对接：`queryRegions`/`queryTerminals`/`terminalOperator`（含 action 10-16 会议会控）、广播任务全系、`startTtsTask`、`linkTask/send`（rule 0-9）、`sosLinkage/add|confirm`、`records/query`/`record/asr`/`startSummary`/`getSummaryStatus`、事件订阅 4 接口、`cameras/queryRegions|queryCameras|getPreviewUrl`、App 5 接口、`sms/syncSmsTemplateList`。

无接口须模拟：短信独立收发/回执、GIS 地图与空间分析、PDT 集群、MCU 会议管理与多画面合成、三维演练/预案推演、视频 PTZ/回放、报警联动规则 CRUD、录音 HTTP 下载、会议录制。

公共约定：全部 POST + JSON；鉴权 `sha256(secretId+'&'+timestamp+'&'+secretKey)` 三 Header（现 `src/api/sign.ts` 已实现）；推送走 HTTP 回调或 `ws://ip:11926/`。

### 场景页统一结构

顶部：编号 + 名称 + 阶段标签 + 核心价值。下方 7 个页签：

1. 场景故事 — 原文故事段落
2. 场景卡片 — 参与角色/触发条件/核心目标/业务对象（表格）
3. 业务流程 — 左侧 6-7 步可点击时间线，右侧交互工作区（slot）；点步骤高亮对应操作区
4. 角色动作 — 步骤/角色/业务动作/系统响应四列表，操作事件实时追加
5. 依赖功能 — 能力/使用方式/数据归属三列表，每行带 `【已有依据】/【需对接】/【模拟】` 标签
6. 合同边界 — 合同依据 + 待确认清单（警示色）
7. 验收建议 — 4 条可勾选验收项 + 完成度

## 数据关联原则（来自建设方案 §3.2）

- 事件—通信：电话/会商/PDT组呼/视频点播/通知记录关联事件编号、操作人员、起止时间
- 事件—任务：任务编号、责任单位/人员、下达/接收/完成时间统一管理
- 任务—移动反馈：文字/图片/视频/位置同时关联任务与事件
- GIS—资源：固定摄像头固定坐标；移动终端标注最近位置与采集时间，不以固定位置冒充实时
- 通信状态—业务状态：短信送达、电话接通、人员确认、任务执行、任务完成五类状态分别记录

## 验证方式

1. `npm run build`（vue-tsc 严格类型检查 + vite 构建）通过
2. Playwright 逐场景截图 + 主流程点击实证（8 个场景各走一遍）
3. 标注检查：所有无 API 能力均带「模拟/需对接」标签
4. QA 记录写入 `engineering/qa/YYYY-MM-DD-eight-scenarios.md`
